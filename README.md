Polpas Sul - Point of Sale (POS) System

A single-file, offline-first web application for Point of Sale (POS) management built for the local business Polpas Sul.

🚀 Features

Front-of-House (POS): Interactive cart with product search by name, barcode, and quantity shortcuts (e.g., 5*40).

Payment Management: Supports Cash, Pix, Debit, Credit, and Split Payments with automatic change calculation.

Promotion Engine: Automated volume discounts and promotional pricing tied to specific dates or payment methods.

Cash Register Control: Register opening/closing, cash influx and outflux tracking with balance verification.

Inventory Management: Product registration, editing, and real-time stock tracking with low-stock alerts.

History & Reports: Detailed sales logging, receipt printing for thermal printers, and CSV data export.

Security & Data Handling: Secure user authentication with PBKDF2 hashing, role-based access control (Manager/Cashier), auto-lock, and JSON backup/restore capabilities.

🛠️ Tech Stack

HTML5 & CSS3 (Responsive UI with Dark Mode support)

JavaScript (ES6+) (Core business logic and state management)

LocalStorage API (Offline-first persistent data storage)

Polpas Sul - Sistema de Ponto de Venda (PDV)

Aplicação web de Ponto de Venda (PDV) offline desenvolvida num único ficheiro (Single-File Web App) para o comércio local Polpas Sul.

🚀 Funcionalidades

Frente de Caixa (POS): Carrinho interativo com pesquisa por nome, código de barras e atalhos de quantidade (ex: 5*40).

Gestão de Pagamentos: Suporte para Dinheiro, Pix, Débito, Crédito e Pagamento Misto (dividido), com cálculo automático de troco.

Regras de Promoção: Descontos automáticos por quantidade e preços promocionais associados a datas ou métodos de pagamento.

Controlo de Caixa: Abertura e fecho de caixa, registo de suprimentos e sangrias com conferência de valores.

Gestão de Produtos: Registo, edição e controlo de stocks com alertas de stock mínimo.

Histórico e Relatórios: Registo de vendas, impressão de recibos em formato térmico e exportação em CSV.

Segurança e Dados: Autenticação segura com hash PBKDF2, controlo de acessos por perfil (Gerente/Caixa), bloqueio automático e sistema de backup/restauração em JSON.

🛠️ Tecnologias Utilizadas

HTML5 & CSS3 (Interface responsiva com suporte a Dark Mode)

JavaScript (ES6+) (Lógica de negócio e manipulação de estado)

LocalStorage API (Armazenamento de dados local offline)
